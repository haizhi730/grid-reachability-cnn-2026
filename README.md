# 二维栅格地图可达性预测

本仓库对应 2026 年秋季深度学习课程设计。任务是在静态 25×25 占据栅格上预测固定起点和终点之间的车身可达性。实验使用 3×3 格的轴对齐方形车身，中心只走上下左右相邻格。

## 在 CPU 上重跑

克隆仓库或下载源码后，在包含 `experiment.py` 的目录运行以下命令。建议使用 Python 3.12。实测环境为 Apple M5、macOS 26.5.2、Python 3.12.14、PyTorch 2.9.1、NumPy 2.2.6 和 Matplotlib 3.10.7，使用 4 个 CPU 线程。六次拟合累计约 87 秒，数据生成、评估及出图另计。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py --out results_rerun --threads 4
python verify_results.py results_rerun
python figures.py results_rerun
```

`--out` 使用新目录或空目录。训练时每轮会打印训练及验证损失，实验完成后，结果目录内会有逐图预测、汇总指标和六个模型权重。`verify_results.py` 用独立的滑窗碰撞检查和四向可达传播复核所有标签，同时核对地图编号、摘要以及从逐图预测重算的指标。

同一台机器从头重跑时，训练日志和逐图预测一致。跨平台或不同版本运行时，PyTorch 的浮点结果可能有差异。[PyTorch 2.9 可复现性文档](https://docs.pytorch.org/docs/2.9/notes/randomness.html)

## 数据和模型

在内侧第 5–19 列选竖墙，相邻墙至少相隔 4 列。每道墙抽取 1 个候选开口，有 30% 的概率增加第 2 个。开口宽度从 0 至 6 格，概率依次为 6%、10%、14%、19%、19%、18%、14%。在内侧行随机放置非零宽度的开口，再叠加 3–8 个长、宽各为 1–4 格的矩形障碍，清空起终点的 3×3 车身范围。坐标从 0 起算，按行、列记录。S 为 (12, 2)，G 为 (12, 22)。

| 地图划分 | 种子 | 墙数 | 地图量 | 实际可达 |
| --- | ---: | --- | ---: | ---: |
| 训练 | 202601 | 1、2 各半 | 5,000 | 2,099 |
| 验证 | 202602 | 1、2 各半 | 800 | 310 |
| 同分布测试（`id`） | 202603 | 1、2 各半 | 1,600 | 642 |
| 三墙测试（`ood`） | 202604 | 3 | 1,600 | 196 |

以原始整图比对上下和左右翻转以及组合翻转的规范摘要，全部划分共 9,000 个不同地图组。对 3×3 邻域中含障碍的每个中心格标记碰撞，再用四连通 BFS 产生可达标签。点机器人 BFS 在原始占据图搜索，列净空规则检查起终点之间每一列是否至少有一个可放置车身中心的格。膨胀图 BFS 与标签生成方法相同，用于一致性核对。

两组卷积网络各有 28,737 个参数，分别读取原始占据图或膨胀图。它们共享卷积结构和训练超参数。每组用 17、29、43 三个随机种子训练，每次 14 轮，批大小 128，Adam 学习率 0.001。损失为二元交叉熵，以验证损失最低的轮次保存权重。训练完成才对两组测试图推理，以 0.5 为阈值。

## 文件与生成结果

| 文件 | 内容 |
| --- | --- |
| `grid.py` | 地图生成、镜像去重、车身碰撞判定和 BFS。 |
| `experiment.py` | 模型定义、训练、基线与测试指标。 |
| `verify_results.py`、`figures.py` | 复核结果和生成报告中的图。 |
| `results_rerun/maps.npz`、`map_manifest.csv` | 原始占据图和地图清单。对应划分内数组按清单顺序排列，`True` 表示有障碍。地图编号从 1 起，数组索引从 0 起。 |
| `results_rerun/metrics.json`、`training_history.csv` | 实验配置、每次训练的最佳轮次、逐轮损失和测试指标。 |
| `results_rerun/test_predictions.csv` | 每张测试图的标签、三种基线判定及各 CNN 的概率和判定。`*_p` 为概率，`*_pred` 为判定。 |
| `results_rerun/checkpoints/` | 六个验证损失最小的模型权重。 |
| `results_rerun/figures/` | 报告的三个图，以及示例地图编号和概率。 |
